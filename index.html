    プロフィール

    東京都市大学 人間科学部 人間科学科の古溝修都です。

    頭の中にある遊びを、AIと対話しながら、実際に遊べるゲームやアプリにしています。ルールの設計から演出の調整、公開までを一人で形にしています。

    今、鬼ごっこ × バスケのゲーム「タグ×ダンク」の開発を中心に進めています。

    • Flutter
    • HTML
    • CSS
    • JavaScript
    • Firebase
    • GitHub Pages
    • AI(Gemini など)

    ゲームを始めるハードルを、少し下げたい。

    誰でも始められて、公平に楽しめて、続けられる。そんなゲームを作りたいと思っています。

    ゲームの世界では、みんな初心者から。

    生まれつきの体格や才能は、ゲームの世界ではあまり関係ありません。誰もが初心者から始まるからこその面白さがあり、それが救いになる子どももいると思い、ゲームを作り始めました。

    遊ぶ上でのバリアを壊す。

    操作しにくい、音が大きい、意味が分かりにくい。そうしたバリアを見つけて改善することを、いつも意識しています。

    リスクの分だけ、リターンは大きく。

    「これを使えば絶対勝てる」という手は作りません。効果が大きいものほど条件や危険も大きくして、駆け引きを楽しめるようにしています。
